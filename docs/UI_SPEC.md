# Spesifikasi UI Bagi Layar

UI mengikuti mockup yang disetujui: gaya Windows 11 modern, latar terang, aksen biru, panel kiri Workspace/Daftar Jendela/Aksi Cepat, area tengah Monitor Aktif dengan preview layout, panel kanan Pengaturan Monitor, dan kartu Aksi Cepat di bawah.

## Elemen utama

- Header `Bagi Layar` dengan subjudul `Atur jendela, maksimalkan produktivitas.`
- Monitor 1, Monitor 2, Monitor 3, dan monitor berikutnya muncul dinamis berdasarkan monitor Windows yang terdeteksi.
- Preview monitor 3x2 dengan slot bernomor 1-6 sebagai default.
- Preset 2, 3, 4, 6, 8, 9 jendela serta Kustom.
- Pengaturan resolusi, margin luar, jarak antar jendela, area taskbar, dan kunci layout.
- Daftar jendela aktif di sidebar kiri.
- Tombol Susun Jendela, Pulihkan Layout, Simpan Workspace, dan Pindahkan ke Slot.

Default workspace bernama `ChatGPT 6 Runner`.
